# Portal Hídrico Chaco - Monitoreo Cuenca Chaco

Este proyecto es una plataforma web orientada al monitoreo, visualización y análisis de datos hídricos en la región de la Cuenca del Chaco.

## 🚀 Características del Proyecto

* **Monitoreo en Tiempo Real:** Visualización de variables hídricas críticas.
* **Análisis de Terremotos y Sismos:** Integración de datos geológicos relevantes para la región.
* **Interfaz Adaptativa:** Panel de control optimizado para la gestión y toma de decisiones.

## 🛠️ Tecnologías Utilizadas

* **Frontend:** React / Next.js (Desplegado en [Vercel](https://vercel.com))
* **Control de Versiones:** Git y GitHub

## 📦 Despliegue

El proyecto se encuentra automatizado y desplegado en producción a través de Vercel. Cada actualización en la rama principal generará una nueva versión de forma automática.
